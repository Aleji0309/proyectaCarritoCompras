## 📋 Project Description

The Shopping Cart App simulates a basic e-commerce interface where users can:

- View a list of products
- Add items to a cart
- Remove individual items
- Clear the entire cart
- See the total price update dynamically

All interactions are handled using **pure JavaScript**, with no libraries or frameworks.

## 📌 Key Features

- Add to cart functionality  
- Quantity and price updates  
- Remove individual items or empty the cart  
- Real-time DOM updates  
- Responsive layout for mobile and desktop

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaCarritoCompras.git
````

2. Navigate to the project folder:

```bash
cd proyectaCarritoCompras
```

3. Open the `index.html` file in your browser.

> No installation or build tools required.
