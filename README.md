# Shopping Cart  

## Description  
This project is a **shopping cart** web application created as part of a **Udemy course**. The goal of the project was to build a functional e-commerce shopping cart where users can add, remove, and update items in their cart. It was built using **HTML**, **CSS**, and **JavaScript**.

## What I Learned  
This project helped me improve my **JavaScript** skills, particularly in managing the **shopping cart state**, handling user actions like adding/removing items, and updating the cart display dynamically. I also worked on creating a **responsive design** and improving the **user experience** using **CSS**.

## Ongoing Development  
I plan to add more features, such as **user accounts**, **order processing**, and **payment integration**. Additionally, I intend to improve **performance** and optimize the user interface for better accessibility.
